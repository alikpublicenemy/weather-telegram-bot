Личный Telegram-бот: ежедневная погода + расписание WebUntis (GitHub Actions)

Что делает
- Каждый день примерно в 07:07 по времени Europe/Berlin GitHub Actions запускает отправку.
- Бот отправляет текущую погоду, максимум/минимум температуры, осадки и совет по одежде.
- Затем он добавляет расписание WebUntis на сегодня, полученное через личную iCal-подписку.
- Домашний компьютер может быть выключен.
- GitHub иногда задерживает запланированный запуск на несколько минут.

Часть 1. Получи личную iCal-ссылку в WebUntis
1. Войди в WebUntis через браузер.
2. Открой «Mein Stundenplan» / «Моё расписание».
3. В нижней панели под расписанием нажми меню с тремя точками.
4. Выбери «iCal-Abo verwalten» / «Управление iCal-подпиской».
5. Если доступно, выбери формат «Standard», затем нажми «Link erstellen» / «Создать ссылку» и скопируй ссылку.
6. Это персональная секретная ссылка: любой, у кого она есть, может получить данные календаря. Не публикуй её и не отправляй в чат. Если такого пункта нет, школа могла отключить iCal-подписку — уточни у школы; не присылай пароль WebUntis.

Часть 2. Обнови файлы в своём GitHub-репозитории
1. Распакуй новый архив weather_telegram_bot_cloud.zip.
2. Скопируй файлы из распакованной папки в локальную папку репозитория, подтвердив замену файлов.
3. Убедись, что в копируемых файлах есть .github/workflows/daily-weather.yml.
4. Не копируй настоящий файл .env и никогда не добавляй токены или iCal-ссылку в код.
5. В GitHub Desktop сделай Commit, затем Push origin.

Часть 3. Сохрани ссылку в секрете GitHub
На сайте GitHub открой репозиторий -> Settings -> Secrets and variables -> Actions -> New repository secret.
Создай секрет:
- Name: WEBUNTIS_ICAL_URL
- Secret: вставь скопированную приватную iCal-ссылку целиком
Нажми Add secret.

Два существующих секрета не удаляй:
- BOT_TOKEN — токен от @BotFather
- TELEGRAM_USER_ID — твой числовой Telegram ID

Часть 4. Проверь вручную
1. Открой вкладку Actions репозитория.
2. Слева выбери workflow «Daily weather and WebUntis timetable».
3. Нажми Run workflow -> Run workflow.
4. Дождись завершения и проверь сообщение в Telegram. В сообщении сначала будет погода, ниже — расписание на сегодня.
5. Если расписание не отображается, открой логи запуска и проверь доступность ссылки; никогда не копируй саму ссылку в публичный лог или чат.

Если пункта iCal нет
Некоторые школы не разрешают личную iCal-подписку учащимся. В этом случае сообщи мне только адрес страницы WebUntis (без параметров доступа), и мы подберём другой вариант. Не отправляй пароль, коды подтверждения или приватную ссылку.

Настройки
- Время запуска: 07:07 Europe/Berlin.
- Город погоды, координаты и часовой пояс находятся в настройках bot.py/.env.example.
- Для локального теста используй .env только на своём компьютере и не коммить его в GitHub.
