Личный Telegram-бот: погода + личное расписание WebUntis (GitHub Actions)

Что делает
- Каждый день около 07:07 по времени Europe/Berlin GitHub Actions запускает отправку.
- Бот отправляет текущую погоду, максимум/минимум температуры, вероятность осадков и совет по одежде.
- Затем входит в WebUntis по логину и паролю и запрашивает личное расписание пользователя.
- В субботу и воскресенье не обращается к WebUntis и сообщает, что сегодня выходной; погодная сводка всё равно приходит.
- Домашний компьютер может быть выключен.
- GitHub иногда задерживает запланированный запуск на несколько минут.

ВАЖНО О БЕЗОПАСНОСТИ
Для автоматического входа пароль WebUntis будет сохранён в GitHub Secrets. GitHub шифрует значения Secrets и не показывает их при обычном просмотре, но при запуске программы секрет передаётся процессу GitHub Actions. Используй этот способ только если тебе комфортно хранить учётные данные у GitHub. Репозиторий лучше оставить Private. Никогда не вставляй логин/пароль в исходный код, коммит или Telegram.

Настройка GitHub Secrets
1. Открой свой репозиторий на GitHub.
2. Settings -> Secrets and variables -> Actions.
3. Создай/сохрани четыре секрета:
   - BOT_TOKEN — токен от @BotFather.
   - TELEGRAM_USER_ID — твой числовой Telegram ID.
   - WEBUNTIS_USERNAME — логин, которым ты обычно входишь в WebUntis.
   - WEBUNTIS_PASSWORD — пароль, которым ты обычно входишь в WebUntis.
4. Существующий WEBUNTIS_PUBLIC_URL больше не нужен этой версии. После успешного теста его можно удалить.

Сервер и школа уже настроены по ссылке, которую пользователь прислал:
- server: wirtschaftsschule.webuntis.com
- school: wirtschaftsschule
Если эта школа использует отдельный адрес API или отключила старый JSON-RPC API, вход может не сработать — тогда посмотрим на журнал Actions. Пароль не присылай в чат.

Обновить файлы репозитория
1. Распакуй архив.
2. Скопируй файлы из папки weather_telegram_bot_webuntis_login в локальную папку своего репозитория, подтверждая замену.
3. Не загружай настоящий файл .env в репозиторий.
4. Через GitHub Desktop сделай Commit, затем Push origin.

Проверка
1. Перейди GitHub -> Actions -> Daily weather and WebUntis timetable.
2. Нажми Run workflow.
3. Для теста понедельника укажи дату в поле target_date, например 2026-10-12. Чтобы запросить расписание на текущий день, оставь поле пустым.
4. Посмотри сообщение в Telegram. Если расписание не пришло, открой журнал выполнения Actions и пришли скриншот ошибки, скрыв возможные личные данные. Не присылай Secrets.

Если код WebUntis сообщает, что логин/пароль неверны, проверь, что это те же данные, с которыми ты входишь на сайт. Если сайт использует дополнительную защиту или школа ограничивает API-доступ, потребуется другой согласованный способ интеграции.

Обычный запуск — около 07:07 Europe/Berlin. Погода берётся из Open-Meteo. Город и координаты настроены в bot.py.
