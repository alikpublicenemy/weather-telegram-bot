Личный Telegram-бот: погода + публичное расписание WebUntis (GitHub Actions)

Что делает
- Каждый день около 07:07 по времени Europe/Berlin GitHub Actions запускает отправку.
- Бот отправляет текущую погоду, максимум/минимум температуры, вероятность осадков и совет по одежде.
- Затем запрашивает расписание на сегодня из публичной ссылки WebUntis.
- Домашний компьютер может быть выключен.
- GitHub иногда задерживает запланированный запуск на несколько минут.

Подключение публичной ссылки WebUntis
1. В WebUntis открой расписание и в меню с тремя точками выбери „Öffentliche Link kopieren“.
2. Убедись, что ссылка открывается в приватном/инкогнито окне без входа в WebUntis. Публичное расписание должно быть разрешено школой.
3. Не вставляй ссылку в исходный код и не публикуй её. Добавь её в GitHub Secrets (см. ниже).

Обновить файлы репозитория
1. Распакуй этот архив.
2. Скопируй файлы из папки weather_telegram_bot_public_webuntis в локальную папку твоего репозитория, подтверждая замену.
3. Не копируй настоящий файл .env в репозиторий; он должен оставаться локальным.
4. Через GitHub Desktop сделай Commit, затем Push origin.

Настроить GitHub Secrets
На сайте GitHub открой репозиторий -> Settings -> Secrets and variables -> Actions.
Добавь/сохрани три секрета:
- BOT_TOKEN — токен от @BotFather.
- TELEGRAM_USER_ID — твой числовой Telegram ID.
- WEBUNTIS_PUBLIC_URL — полный URL, скопированный через „Öffentliche Link kopieren“.

Важно: ранее использовавшийся секрет WEBUNTIS_ICAL_URL больше не используется. Можно удалить его после того, как новый вариант проверен.

Проверить
1. Открой вкладку Actions.
2. Выбери „Daily weather and WebUntis timetable“.
3. Нажми Run workflow -> Run workflow.
4. Проверь сообщение в Telegram и открой журнал задания, если расписание не подтянулось.

Безопасность и ограничения
- Секрет не должен попадать в код, коммиты или логи.
- Скрипт использует только общедоступную страницу расписания; логин и пароль WebUntis не нужны.
- Если у школы закрыт публичный доступ, этот способ не сработает. Не отправляй пароль или коды подтверждения; потребуется другой официальный способ доступа.
- Уроки, кабинет и преподаватель будут показаны только в той мере, в какой WebUntis отдаёт их публичному расписанию/API.

Время запуска — 07:07 Europe/Berlin. Город погоды, координаты и часовой пояс находятся в настройках bot.py/.env.example.
